# Web Scraper

A Python-based web scraping project that tracks book prices using data collected from [Books to Scrape](https://books.toscrape.com/).

## Project Goals

* Learn web scraping fundamentals
* Extract structured data from web pages
* Track product prices over time
* Store and process scraped data
* Handle pagination and errors
* Build a reliable data collection pipeline

## Tech Stack

* Python
* Requests
* BeautifulSoup
* Pandas
* Pytest

## Data Source

[Books to Scrape](https://books.toscrape.com/) is a demo website created specifically for practicing web scraping.
